# AI-Inspector 🔬

> Автоматизированная система проверки, валидации и рецензирования студенческих отчетов по дисциплине **«Цифровая грамотность и использование ИИ»** (Карагандинский медицинский университет).

Репозиторий проекта: [https://github.com/argokz/ai-inspector.git](https://github.com/argokz/ai-inspector.git)

---

## 🌟 Возможности системы

* **Академический аудит по 8 критериям (100 баллов):**
  1. Титульный лист и метаданные (10 б.)
  2. Формулировка целей и задач (5 б.)
  3. Обзор литературы по 5 направлениям: *Эпидемиология, Этиология, Диагностика, Профилактика, Терапия* (20 б.)
  4. Статистические таблицы (3 таблицы, требование $\ge 15$ регионов, детекция МКБ-11, запрет Википедии) (20 б.)
  5. Подраздел работы с ResearchRabbit (карты связей, коллекции, скриншоты) (10 б.)
  6. Промт-инжиниринг и протокол ИИ (модель, дата, 5-компонентный промт, верификация) (15 б.)
  7. Аналитические выводы и ограничения ИИ/баз данных (10 б.)
  8. Библиографический список по стандарту AMA с отловом «голых» ссылок (10 б.)

* **Прямая инспекция верстки Microsoft Word (.docx):**
  * Проверка рамки титульного листа (`<w:pgBorders>` с ограничением `firstPage`).
  * Проверка скрытия номера страницы на титульнике (`<w:titlePg>`).
  * Контроль полей страницы: левое 3 см, правое 1 см, верх/низ 2 см (`<w:pgMar>`).
  * Точный подсчет строк в таблицах Word (`<w:tbl>`, `<w:tr>`).

* **Смысловое рецензирование через Gemini AI:**
  * Анализ соответствия аннотаций клиническим направлениям.
  * Оценка качества промта студента.
  * Формирование персонального отзыва преподавателя для студента.

* **Интерактивный React Web-интерфейс:**
  * Drag-and-drop загрузка `.docx` / `.txt` или вставка текста.
  * Визуальная шкала баллов, оценка по ECTS (A, B, C, D, F) и GPA.
  * Детальный чек-лист с подсветкой ошибок и штрафов.

## 🚀 Быстрый старт

### 1. Настройка окружения
В корне проекта создан файл `.env`:
```env
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
```
*(Получить бесплатный ключ можно на [Google AI Studio](https://aistudio.google.com/)).*

---

### 2. Запуск через консоль (CLI)

#### Обычная проверка отчета (автономно, 0.05 сек):
```bash
python3 report_validator.py "Лысенко 1 кредит.docx"
```

#### Проверка с подключением Gemini AI-рецензента:
```bash
python3 report_validator.py "Лысенко 1 кредит.docx" --ai
```

#### Выгрузка в формате JSON:
```bash
python3 report_validator.py "Лысенко 1 кредит.docx" --json
```

---

### 3. Запуск веб-интерфейса (React UI)

Запустите локальный сервер (чистый Python, 0 сторонних библиотек):
```bash
python3 server.py
```
Откройте в браузере: **`http://localhost:8000`**
